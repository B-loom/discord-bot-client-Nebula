Nebula

Tes comptes Discord et tes bots dans une seule application. Une fenêtre par compte, le même client pour tous.

Télécharger pour Windows Serveur Discord Code source

Windows 64 bits · installateur · mises à jour automatiques

Ce que fait Nebula

Comptes et bots ensemble

Connexion par e-mail, par token de compte ou par token de bot. Captcha et double authentification gérés.

Autant de comptes que voulu

Chacun dans sa fenêtre et sa session, rangés entre utilisateurs et bots.

Détection des jeux

Le jeu en cours apparaît sur ton profil, sans le client officiel.

Éditeur de messages

Embeds, boutons, fichiers et catalogue d'émojis, pour les bots.

Tout en français

L'interface, les plugins et jusqu'aux messages d'erreur.

Mises à jour

Nebula prévient quand une version paraît, la télécharge et l'installe au redémarrage.

Installer

  1. Télécharge Nebula-win-x64.exe avec le bouton plus haut.
  2. Lance-le. Windows affichera un avertissement, l'application n'étant pas signée par un certificat payant : passe par Informations complémentaires puis Exécuter quand même.
  3. Choisis le dossier d'installation. C'est tout.

À lire avant d'utiliser Nebula

Un client tiers est contraire aux conditions d'utilisation de Discord.

Se connecter avec un compte utilisateur depuis autre chose que le client officiel peut entraîner la désactivation de ce compte. Les bots, eux, passent par l'API officielle et ne posent pas ce problème.

Aucune responsabilité n'est assumée.

Ni pour un compte banni, ni pour un bot supprimé, ni pour une perte de données, ni pour quoi que ce soit d'autre. Tu l'utilises à tes risques.

Nebula n'est pas un projet original.

C'est une version modifiée de aiko-chan-ai/DiscordBotClient, à qui revient tout le travail de fond. Quand Discord change et que le client casse, la correction est attendue du projet d'origine avant d'être reprise ici.

Un bug, une question ?

Tout se passe sur le serveur Discord. Pour un bug, dis ce que tu faisais, ce qui s'est passé, et si tu étais connecté avec un compte ou avec un bot : les deux ne suivent pas le même chemin dans l'application, et la réponse en dépend.
